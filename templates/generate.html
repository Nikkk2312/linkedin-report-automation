How to Get LinkedIn API Access

Step 1: Create a LinkedIn Developer App
  1. Go to LinkedIn Developer Portal
  2. Click "Create App"
  3. Fill in your app name, LinkedIn Page (create one if needed), and upload a logo
  4. Accept the terms and click "Create App"
Step 2: Request API Access
  1. In your app, go to the "Products" tab
  2. Request access to "Advertising API" (required for campaign data)
  3. Also add "Share on LinkedIn" and "Sign In with LinkedIn using OpenID Connect"
  4. Wait for approval (usually instant for Advertising API if you have an active ad account)
Step 3: Generate an Access Token
  1. Go to the "Auth" tab in your LinkedIn app
  2. Note your Client ID and Client Secret
  3. Use the LinkedIn Token Generator to create your access token:
Open LinkedIn Token Generator Select the r_ads, r_ads_reporting, and r_organization_social scopes
Important: LinkedIn access tokens expire after 60 days. You can set up a refresh token in Settings for automatic renewal. The token generated from the Token Generator tool is valid for 60 days.
Step 4: Find Your Ad Account ID
  1. Go to LinkedIn Campaign Manager
  2. Select your ad account
  3. The Account ID is the number in the URL after /accounts/
  4. Example: linkedin.com/campaignmanager/accounts/123456789/
Required OAuth Scopes
r_ads r_ads_reporting r_organization_social r_liteprofile (optional) rw_ads (optional, for management)
r_ads and r_ads_reporting are required. Others are optional for extended features.
