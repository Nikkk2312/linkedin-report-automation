Quick Reference

Authentication: No auth required (local use). Set WEBHOOK_API_KEY in settings for external access.
Content Type: POST endpoints accept application/json
Response Format: All API endpoints return JSON
Rate Limits: None (local server)

Example Usage

# List all reports
curl http://localhost:5000/api/reports

# Search for reports/pages
curl "http://localhost:5000/api/search?q=campaign"

# Export trends as CSV
curl http://localhost:5000/api/trends-csv -o trends.csv

# Generate AI insights (cached)
curl http://localhost:5000/api/insights/MY_REPORT

# Get health scores
curl http://localhost:5000/api/health-scores/MY_REPORT
